10. FOOTPRINT DRAWING RULES

LANDS: IPC-7351 NOMINAL
(OR THE MANUFACTURER'S RECOMMENDED
LAND, IF THE DATASHEET DRAWS ONE)

PAD CORNERS: ROUND-RECT, 10%

OVERLAY: 0.2mm LINE, OUTSIDE THE
PADS, INSIDE THE COURTYARD

ALL MECHANICAL-LAYER LINES: 0.1mm

COURTYARD (M27): RECTANGLE

COMPONENT OUTLINE (M19): BODY OUTLINE

COMPONENT CENTRE (M37): CROSS AND
CIRCLE (0.3mm ARMS, 0.15mm RADIUS)

DIMENSIONS (M5): BODY X AND Y SIZE,
TRUE TO THE M19 OUTLINE

3D BODY (M13): STEP MODEL


11. FOOTPRINT NAMES

2-PIN CHIPS (0201, 0402, 0603, 0805,
1206): TYPE + SIZE
e.g. RES0603, CAP0402

EVERYTHING ELSE: PACKAGE NAME FROM
THE DATASHEET, NEVER THE MPN
e.g. SMB, SOT26, D0008A, CP-32-12,
T3255Y-8, IND1028, LQFP48

13. INSTALL THE comp SKILL (ONCE)

NEEDS: CLAUDE CODE, THE eda-agent MCP
SERVER CONNECTED TO ALTIUM, AND
python3 WITH PyMuPDF (pip install
pymupdf) FOR THE HELPER SCRIPTS.

1. UNZIP skills.zip (PROJECT ROOT)
2. COPY THE FOLDER skills/comp TO
   ~/.claude/skills/comp
   (WINDOWS: %USERPROFILE%\.claude\
   skills\comp)
3. RESTART THE AGENT, OR SIMPLY ASK IT:
   "INSTALL THE SKILL IN skills.zip
   OF THIS PROJECT"
4. CHECK: /comp APPEARS IN THE SKILL
   LIST


14. USE THE comp SKILL

OPEN ALTIUM, CONNECT eda-agent, THEN
TELL THE AGENT, e.g.:
"USE THE comp SKILL: CREATE THE SYMBOL
AND FOOTPRINT FOR <MPN>"
(A LIST OF MPNs IS FINE)

THE AGENT: FINDS THE DATASHEET (IF A
DOWNLOAD IS BLOCKED, DROP THE PDF
IN A scratch/ds-... FOLDER AND SAY
SO), BUILDS THE PART IN SCRATCH
LIBS, CHECKS IT, AND REPORTS WHAT
IT ASSUMED. THE SCRATCH LIBRARIES ARE
THROWAWAY; NO PROJECT LIBRARY IS
WRITTEN. IT LOGS THE WORK IN
HOUSE_STANDARD.md.

IF ALTIUM 365 IS SET UP (SECTION 15)
THE AGENT ALSO UPLOADS THE PART:
SYMBOL AND FOOTPRINT INTO Components/
Models, AND A NEW COMPONENT CMP-NNNNN
IN THE BEST-MATCHING Components/
FOLDER (A MOSFET GOES TO Transistors).
PARAMETERS: MPN AND DES ONLY.
UPLOADS CANNOT BE DELETED BY THE
AGENT: CHECK THE PART FIRST.

CHANGES TO THE SKILL OR THE STANDARD:
BUILD A NEW skills.zip AND CHECK IT
IN, SO EVERYONE GETS THE UPDATE.


15. ALTIUM 365 UPLOAD VIA NEXAR
(OPTIONAL: LETS THE AGENT UPLOAD
LIBRARIES AND CREATE COMPONENTS IN THE
WORKSPACE INSTEAD OF CLICKING)

ONE-TIME SETUP (PER PERSON):
1. CREATE A NEXAR ACCOUNT AT
   nexar.com AND OPEN THE API PORTAL
   (nexar.com/api, APPS)
2. USE OR CREATE AN APP WITH:
   - AUTHORIZATION CODE GRANT ON
   - REDIRECT URL
     http://localhost:3000/login
   - DESIGN SCOPES ENABLED (design.
     domain, user.access)
3. COPY THE APP'S CLIENT ID AND
   CLIENT SECRET. THE SECRET IS
   PRIVATE: NEVER PASTE IT INTO THE
   CHAT OR CHECK IT IN
4. IN POWERSHELL:
   setx EDA_AGENT_NEXAR_APP_ID "<id>"
   setx EDA_AGENT_NEXAR_CLIENT_SECRET
   "<secret>"
   (TYPE THE REAL VALUES, NOT THE
   <...> PLACEHOLDERS)
5. IF THE AGENT RUNS IN WSL, ALSO
   LET THE VARIABLES THROUGH:
   setx WSLENV
   "EDA_AGENT_NEXAR_APP_ID:EDA_AGENT_
   NEXAR_CLIENT_SECRET"
   THEN wsl --shutdown (A SERVER
   STARTED FROM WSL DOES NOT SEE
   WINDOWS VARIABLES OTHERWISE)
6. CLOSE ALL TERMINALS, OPEN A NEW
   ONE AND CHECK THE VARIABLE IS
   SET: echo $env:EDA_AGENT_NEXAR_
   APP_ID
7. SIGN IN ONCE (BROWSER OPENS,
   USE YOUR ALTIUM 365 ACCOUNT):
   eda-agent altium365-login
   (eda-agent altium365-logout
   FORGETS THE LOGIN)
8. RECONNECT THE MCP SERVER (/mcp) AND
   ASK THE AGENT TO RUN
   altium365_check_setup. IT SHOULD
   SAY ROUTE nexar AND OFFER PUBLISH
   SYMBOL, PUBLISH FOOTPRINT, RELEASE
   COMPONENT, SET PARAMETERS

ALTERNATIVE: A WORKSPACE API TOKEN
(ADMIN > DEVELOPER) IN
EDA_AGENT_ALTIUM365_TOKEN AND THE
WORKSPACE DOMAIN IN
EDA_AGENT_ALTIUM365_DOMAIN

RULES:
- THE AGENT PREVIEWS, THEN SENDS ONLY
  AFTER YOU CONFIRM (confirm=True)
- NOTHING IS PUBLISHED FROM scratch/
  LIBRARIES WITHOUT YOUR APPROVAL
- NEXAR TERMS: DATA THE API RETURNS
  MAY NOT BE KEPT MORE THAN 24 HOURS
  (INCLUDING COPIES SAVED IN A CHAT).
  THE LOGIN ITSELF LASTS 24 HOURS:
  SIGN IN AGAIN WHEN IT EXPIRES
- WORKSPACE LIBRARY FOLDERS: SEE
  Components/... (Resistors,
  Capacitors, Integrated Circuits ...)
